# Product Overview

The DeepRacer Custom Console is a community-developed web interface that replaces the standard AWS DeepRacer manufacturer UI. It provides an enhanced user experience with a modern Cloudscape-based interface for controlling and managing DeepRacer vehicles.

## Key Features
- Modern Cloudscape UI design
- Simple installation via Debian package
- Easily reversible - can restore original console
- Open-source and community-supported
- Fully customizable for developers

## Target Users
- DeepRacer enthusiasts looking to customize their racing experience
- Developers wanting to extend DeepRacer functionality
- Community members contributing to the AWS DeepRacer ecosystem

## Distribution
- Distributed as Debian packages via GitHub releases
- Replaces the original `aws-deepracer-device-console` package
- Requires SSH access to DeepRacer car for installation
